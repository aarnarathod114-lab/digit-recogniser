    What the network actually sees: your drawing, shrunk to 28 × 28 pixels and centred, the same way its training images were prepared.

    How it works

    The network has 784 inputs (one per pixel), two hidden layers of 256 and 128 neurons, and 10 outputs (one per digit). Every part of it, including backpropagation, is written by hand in Python with NumPy.

    It learned from 55,000 handwritten digits in the MNIST dataset and gets 99.03% right on 10,000 digits it had never seen. This page loads those learned weights and runs the same calculation in JavaScript, so nothing you draw leaves your device.
